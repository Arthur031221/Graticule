# Architecture

Graticule turns a spec and a table into one scene, then writes the scene in four formats. The same code runs in the command line program, the agent skill and the browser playground.

```
spec + table
   |
   v
analyze      region, join, values, classes, palette            src/analyze.js
   |
   v
checks       rules with reasons and fixes                      src/checks.js
   |            (--fix edits the spec and analyzes again)
   v
draw         layout, projection, labels, legend -> scene       src/draw.js
   |
   +--> SVG   src/scene.js + embedded font subsets             src/render.js
   +--> PNG   SVG through resvg (WebAssembly)                  src/render.js
   +--> PDF   scene through pdfkit                             src/pdf.js
   +--> HTML  SVG plus tooltip and data table                  src/html.js
```

## Why a scene

`draw` returns a list of rects, paths, circles, texts and groups. Every output format is a small function over that list, so the PNG cannot disagree with the PDF. The unit tests snapshot the scene (counts, fills, texts), not pixels.

## Modules

| Module | Job |
| --- | --- |
| `spec.js` | Validate a spec. Every problem names the field. |
| `csv.js` | Read CSV or TSV, parse numbers the way spreadsheets print them. |
| `regions.js`, `geo.js` | The region catalogue, loading areas from the bundled TopoJSON, name keys per level. |
| `custom.js` | Read the boundaries of a `custom` region (GeoJSON or TopoJSON): rewind rings for d3, derive key types from the properties, choose an equal-area projection from the extent. |
| `names.js`, `join.js` | Normalise names, find the key column, join rows to areas, report what did not join. |
| `classify.js` | Quantile, equal interval, Fisher-Jenks and manual classes, with round edges that never move a value to another class. |
| `color.js`, `palettes.js` | CIELAB, CIEDE2000, colour vision simulation (Machado 2009), the bundled palettes. |
| `projections.js`, `composite.js` | d3-geo projections with their equal-area flags, and the Albers USA composite. |
| `labels.js` | Pole of inaccessibility per area, greedy label placement with collision checks. |
| `legend.js`, `draw.js`, `scene.js` | Layout and the scene. |
| `fonts.js`, `subset.js` | Per-map font subsets with the HarfBuzz subsetter in WebAssembly. |
| `cli.js` | The command line. |

## Data

`skills/graticule/data` holds the boundaries as quantized TopoJSON (2.9 MB in total), `fonts` the Noto subsets (gzip), `locales` the nine message files and `vendor` two WebAssembly binaries. `scripts/build-data.mjs` and `scripts/build_fonts.py` regenerate them from public sources. Rendering reads them from disk (Node) or fetches them (browser) through one small `assets` interface, which is the only difference between the two.

## Decisions worth knowing

- **Rules before pixels.** A rule that fails stops the render. `--fix` repairs the errors that have one mechanical repair and records each change.
- **The legend is the truth.** Quantile and Jenks edges move to the roundest number that gives every area the class it had. Equal-interval classes have a round width. Either way the legend prints the numbers the classification used.
- **No silent drops.** Rows that do not join, labels left out and areas drawn as dots are all counted in the report.
- **Classes describe what is drawn.** For a region such as Europe the classification uses the areas inside the frame, not the whole table.
- **CJK without a font on the reader's machine.** Each SVG embeds a subset of Noto Sans CJK with only the glyphs it draws, and the PDF embeds the same.
- **One bundle.** `skills/graticule/scripts/graticule.mjs` is built by esbuild from `src/` and committed, so the skill folder runs with `node` alone.

## Tests

Unit tests with `node:test` (`tests/unit`), reference fixtures from mapclassify and colour-science (`tests/fixtures`, regenerated by CI), snapshot signatures (`tests/snapshots.json`), browser tests with Playwright (`tests/e2e`), and the external checks in `verify/` (PROJ, public name lists, file parsers). See `docs/verification.md` for the numbers.
